09 / FAQ

首次使用最容易误解的四件事。

安装后必须输入激活码吗？

不需要。首次联网自动开启 7 天试用，有效试用期间直接关闭激活输入区即可。

为什么网站不再单独提供 Skill ZIP？

Skill ZIP 已随安装器写入本机 AgentSkills 目录，避免用户下载两个文件后不知道先用哪个。

Agent 一定能自动安装 Skill 吗？

不能承诺。不同 Agent 的入口不同，因此手工导入是首选，安装提示词只是辅助。

复制测试提示词会自动发微信吗？

不会。网页和开始页面只复制文本；用户仍需粘贴给 Agent，并由 Agent 按安全规则确认执行。
